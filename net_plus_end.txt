Kapitel 19: Lösungen zu den netsh-Aufgaben
netsh -c interface dump>netcnfig.txt

Liest die Netzwerkkonfiguration und schreibt sie in eine Datei namens netonfig.txt.
netsh -f netcnfig.txt

dabei die vorhandenen Einstellungen.
netsh wlan show profiles

Zeigt die eingerichteten drahtlosen Netzwerkprofile an.
netsh winsock reset

Setzt die Socket-Einstellungen unter Windows zurück – ist unter Umständen bei
Malware sehr nützlich.
netsh firewall set opmode disable

bzw.
netsh firewall set opmode enable

Aktiviert bzw. deaktiviert die Windows-Software-Firewall. Achtung: Bei Windows 7
und Windows 11 werden die Befehle unterschiedlich ausgeschrieben.
