1. Create `CourseMaterials.vue`:
   - Props: `courseId` (Number, required), `isInstructor` (Boolean, default false)
   - Data: `documents` (array), `materialFolder` (string|null), `folderInput` (string), `loading` (boolean), `extracting` (object tracking per-doc extraction state), `scanning` (boolean)
   - On mount: load material folder (GET material-folder) and document list (GET documents)

   **Folder Setting Section** (instructor only):
   - Text input for NC folder path (e.g. "/Kursmaterial")
   - "Ordner verknuepfen" button that POSTs to material-folder endpoint
   - Show current linked folder path if set
   - After setting folder, auto-trigger scan

   **Document List Table:**
   - Columns: Dateiname, Typ (PDF/Markdown icon or badge), Status, Groesse, Hochgeladen
   - Status rendering:
     - 'uploaded': Yellow badge "Hochgeladen"
     - 'extracted': Green badge "Extrahiert"
     - 'error': Red badge "Fehler" with tooltip showing error_message
   - Date formatting: use `new Date(created_at * 1000).toLocaleDateString('de-DE')`
   - File size: format as KB/MB

   **Action Buttons** (instructor only):
   - "Ordner scannen" button (POST scan) -- refreshes file list from NC folder
   - "Alle extrahieren" button (POST extract-all) -- extracts all uploaded docs
   - Per-document "Extrahieren" button (POST extract) for individual extraction (only show for status='uploaded')
   - Show spinner/loading state during extraction

   **Empty State:**
   - If no material folder set: "Kein Materialordner verknuepft. Bitte einen Nextcloud-Ordner auswaehlen."
   - If folder set but no documents: "Keine Dokumente gefunden. Laden Sie PDF- oder Markdown-Dateien in den Ordner hoch und klicken Sie 'Ordner scannen'."

   Use existing Vue 2.7 patterns from the codebase (no Composition API). Use NcButton, NcTextField from @nextcloud/vue if available, otherwise standard HTML with Nextcloud CSS classes. Use axios for API calls (import from @nextcloud/axios). Generate URLs with `generateUrl` from @nextcloud/router.

   - `.course-materials` container styling
   - `.status-badge` with color variants (`.status-uploaded`, `.status-extracted`, `.status-error`)
