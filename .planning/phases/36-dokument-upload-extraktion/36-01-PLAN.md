  <files>app/lib/Service/DocumentService.php, app/lib/Controller/DocumentController.php, app/appinfo/routes.php</files>
  <action>
1. Create `DocumentService.php`:
   - DI: `CourseDocumentMapper`, `CourseMapper`, `IRootFolder`, `LoggerInterface`, `IDBConnection`
   - `setMaterialFolder(int $courseId, string $folderPath, string $userId): void`
     - Verify user is instructor of course (use CourseMapper to load course, check instructorId === userId)
     - Verify folder exists via IRootFolder: `$this->rootFolder->getUserFolder($userId)->get($folderPath)`
     - Update course entity's material_folder field, save via CourseMapper
   - `getMaterialFolder(int $courseId): ?string`
     - Load course, return material_folder
   - `scanFolder(int $courseId, string $userId): array`
     - Load course, get material_folder
     - List files in folder via NC Files API (getUserFolder->get->getDirectoryListing)
     - Filter for .pdf and .md files only
     - For each file not already in DB (check by file_path): create CourseDocument with status='uploaded'
     - Return list of all CourseDocument entities for the course
   - `extractText(int $documentId, string $userId): CourseDocument`
     - Load document by ID
     - Load course, verify instructor
     - Get file content via NC Files API: `$userFolder->get($doc->getFilePath())->getContent()`
     - For PDF: write temp file, run `exec('pdftotext ' . escapeshellarg($tmpFile) . ' -', $output, $returnCode)`, delete temp file. Handle returnCode !== 0 as error.
     - For Markdown: use file content directly as extracted text (strip YAML frontmatter if present via regex `/^---\n.*?\n---\n/s`)
     - Update document: set extracted_text, status='extracted' (or status='error' + error_message on failure)
     - Return updated document
   - `extractAll(int $courseId, string $userId): array`
     - Scan folder first, then extract all documents with status='uploaded'
     - Return list of all documents
   - `listDocuments(int $courseId): array`
     - Return CourseDocumentMapper->findByCourseId($courseId)
     - Map each to jsonSerialize()

2. Create `DocumentController.php`:
   - DI: `$appName`, `IRequest`, `DocumentService`, `RoleService`, `LoggerInterface`, `?string $userId`
   - All methods annotated `@NoAdminRequired`
   - `setFolder(int $courseId)`: POST, reads `folder` from request params, calls setMaterialFolder. Returns 200 or 403/404.
   - `getFolder(int $courseId)`: GET, returns material_folder for the course.
   - `scan(int $courseId)`: POST, calls scanFolder, returns document list.
   - `index(int $courseId)`: GET, calls listDocuments, returns document list.
   - `extract(int $courseId, int $documentId)`: POST, calls extractText, returns updated document.
   - `extractAll(int $courseId)`: POST, calls extractAll, returns document list.
   - Wrap all methods in try/catch, return DataResponse with appropriate HTTP status codes.
   - Use RoleService to verify instructor role where needed (setFolder, scan, extract operations).

3. Add routes to `routes.php` (add after existing course routes):
   ```php
   ['name' => 'document#setFolder', 'url' => '/api/courses/{courseId}/material-folder', 'verb' => 'POST'],
   ['name' => 'document#getFolder', 'url' => '/api/courses/{courseId}/material-folder', 'verb' => 'GET'],
   ['name' => 'document#scan', 'url' => '/api/courses/{courseId}/documents/scan', 'verb' => 'POST'],
   ['name' => 'document#index', 'url' => '/api/courses/{courseId}/documents', 'verb' => 'GET'],
   ['name' => 'document#extract', 'url' => '/api/courses/{courseId}/documents/{documentId}/extract', 'verb' => 'POST'],
   ['name' => 'document#extractAll', 'url' => '/api/courses/{courseId}/documents/extract-all', 'verb' => 'POST'],
   ```

Important implementation notes:
- Use `?string $userId` (nullable) in controller constructor per NC pattern
- Use `escapeshellarg()` for ALL shell arguments to pdftotext (security!)
- Use `sys_get_temp_dir()` for temp file path
- NC Files API: `$this->rootFolder->getUserFolder($userId)` returns the user's home folder
- For file_path in DB, store path relative to user's home folder (e.g. "Kursmaterial/chapter1.pdf")
- Guard pdftotext with `is_executable` check or fallback error message
