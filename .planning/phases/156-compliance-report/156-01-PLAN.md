<objective>
Build the DSGVO-safe, owner-scoped compliance-report backend for certifying courses: one mapper method, one service that decodes the stored VC-JWT for score + frozen recipient name and projects to a strict 5-field DTO, and one thin controller exposing a JSON table endpoint and a CSV download endpoint. Both endpoints call the SAME service method so the on-screen filtered set equals the exported set.

Purpose: REPORT-01..04. This is an export-only recombination of existing, security-reviewed primitives (at-risk export pattern) — NOT a new architecture, NOT analytics.
Output: A queryable, filterable, IDOR-safe certificate report that never emits user_id or email in any surface.
</objective>
