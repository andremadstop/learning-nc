# Phase 26 Plan 01: VirtuProf Chat-Memory

## Objective

Persist VirtuProf chat context across sessions per user in a DB table (`learning_ai_chat_memory`). Load the last N entries as conversation history into each Gemini call. Cap at 50 entries per user — compress oldest 10 into a summary when cap is reached. Provide a DELETE endpoint so users can clear their history (privacy).

## Context

- GeminiService::chat() builds the system prompt — memory context goes here as "Previous conversations" addendum
- VirtuProfController::chat() calls GeminiService — it needs to load + save memory around each call
- Routes in app/appinfo/routes.php
- Migration pattern: Version003900Date20260321000000.php

## Tasks

### Task 1: DB Migration + Entity + Mapper
type: auto

Create `Version004000Date20260321000000.php` — new table `learning_ai_chat_memory`:
- id (auto-increment PK)
- user_id VARCHAR(64) NOT NULL
- role VARCHAR(16) NOT NULL (user/assistant/summary)
- message TEXT NOT NULL
- created_at BIGINT NOT NULL
- Index: (user_id, created_at DESC)

Create `AiChatMemory.php` entity and `AiChatMemoryMapper.php` with:
- findRecentByUser(userId, limit): array — ORDER BY created_at DESC LIMIT N, then reverse
- deleteOldestByUser(userId, keepCount): void — delete all but the N newest rows
- deleteAllByUser(userId): void — full wipe for privacy endpoint
- countByUser(userId): int

**Done criteria:** Files created, migration class name matches filename.

### Task 2: AiChatMemoryService
type: auto

New `app/lib/Service/AiChatMemoryService.php`:

```
loadMemory(userId): array          // last 50 entries, oldest-first
saveExchange(userId, userMsg, assistantMsg): void
  // append user + assistant entry
  // if count > 50: compress oldest 10 into 1 summary entry via Gemini, delete those 10
clearMemory(userId): void          // deleteAllByUser
```

Compression: call `GeminiService::generateNote()` with a mini-prompt asking for a 3-sentence summary of the conversation snippets. If Gemini fails, fall back to a static "Summary of earlier conversation" string. Store as role='summary'.

**Done criteria:** Service class created with correct method signatures.

### Task 3: Wire GeminiService::chat() for memory
type: auto

Add optional `array $memoryEntries = []` parameter to `GeminiService::chat()`.

In `buildSystemPrompt()` (or a new `buildMemoryAddendum()`): append a "Previous conversations:" section with the last N entries formatted as:
```
[User]: question text
[VirtuProf]: answer text
[Summary]: earlier conversation summary
```

Max 10 entries passed to avoid token overflow (AiChatMemoryService passes up to 10 most recent).

**Done criteria:** chat() signature updated, memory addendum appended when non-empty.

### Task 4: Wire VirtuProfController::chat() for memory
type: auto

In `VirtuProfController::chat()`:
1. Inject `AiChatMemoryService $chatMemoryService` via constructor
2. Before Gemini call: `$memory = $chatMemoryService->loadMemory($this->userId, 10)`
3. Pass `$memory` to `$this->geminiService->chat($message, $this->userId, $ragContext, $memory)`
4. On successful answer: `$chatMemoryService->saveExchange($this->userId, $message, $result['answer'])`
5. On fallback: do NOT save (no meaningful exchange)

**Done criteria:** Controller constructor updated, memory loaded/saved per chat call.

### Task 5: clearChatHistory endpoint + route
type: auto

Add to `VirtuProfController`:
```php
/**
 * @NoAdminRequired
 */
#[UserRateLimit(limit: 5, period: 60)]
public function clearChatHistory(): DataResponse
```

Calls `$chatMemoryService->clearMemory($this->userId)`.
Returns `['ok' => true]`.

Add route: `['name' => 'virtuProf#clearChatHistory', 'url' => '/api/virtu-prof/chat-history', 'verb' => 'DELETE']`

**Done criteria:** Endpoint added, route registered.

### Task 6: Frontend — load history on mount + clear button
type: auto

In `VirtuProf.vue`:
- In `mounted()` / `loadState()`: call `GET /apps/learning/api/virtuprof/chat-history` (new endpoint) to load existing chat history and populate `chatMessages`
- Add `GET /api/virtu-prof/chat-history` endpoint in Controller (`getChatHistory`) that returns last 20 entries formatted as `{role, text}` array
- In `handleAction`: add case `'clear-chat-history'` that calls `DELETE /api/virtu-prof/chat-history`, clears `chatMessages = []`

Add a "Clear chat history" button in the chat section of `VirtuProfBubble.vue` (small, below chat, only shown when there are messages).

Emit `@action="{ type: 'clear-chat-history' }"` from VirtuProfBubble.

**Done criteria:** History loads on mount, clear button functional.
