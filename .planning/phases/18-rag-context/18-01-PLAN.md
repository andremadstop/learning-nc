# Phase 18 Plan 01: RAG Context Builder

## Objective

Create `RagContextService.php` that builds a structured context payload from pool questions,
recent wrong answers and Leitner box stats for a given user — then wire it into
`GeminiService::chat()` so VirtuProf answers have concrete learning context.

## Context

- @app/lib/Service/GeminiService.php — extend chat() to accept $ragContext array
- @app/lib/Service/LeitnerService.php — getStats() returns box counts per pool
- @app/lib/Controller/VirtuProfController.php — chat() must pass context from request params
- @app/appinfo/routes.php — virtu_prof#chat route exists

## Tasks

### Task 1: Create RagContextService.php (RAG-01, RAG-02, RAG-03, RAG-04)

type="auto"

**What:** New service at `app/lib/Service/RagContextService.php`.

Implements `buildContext(string $userId, ?int $poolId, ?int $courseId, ?int $lastWrongQuestionId): array`

The returned array has this shape:
```
[
  'pool_name'        => string|null,
  'pool_questions'   => [['text' => ..., 'answers' => [...]], ...],  // up to 15 questions
  'leitner_stats'    => ['box_1' => int, 'box_2' => int, ..., 'box_5' => int, 'total' => int] | null,
  'course_name'      => string|null,
  'last_wrong'       => ['question' => string, 'correct_answer' => string] | null,
  'token_estimate'   => int,
]
```

**Token budget (RAG-04):** estimate ≈ strlen(json_encode($context)) / 4. If over 4000 tokens
(16000 chars), trim `pool_questions` from the end until under budget.

**Privacy (PRIV-04):** No userId, no username, no email in the context payload — only
content data (questions, pool names, box counts).

**DB queries (all direct IDBConnection, no service-layer calls that require userId ownership):**

1. Pool name: `SELECT name FROM learning_pools WHERE id = :poolId`
2. Pool questions (RAG-01): `SELECT q.text, a.text as answer_text, a.is_correct FROM learning_questions q JOIN learning_answers a ON a.question_id = q.id WHERE q.pool_id = :poolId ORDER BY q.id ASC LIMIT 15` — group answers per question in PHP
3. Leitner stats (RAG-03): `SELECT box, COUNT(*) as cnt FROM learning_leitner_items WHERE user_id = :userId AND pool_id = :poolId GROUP BY box` — return as box_1..box_5
4. Course name (RAG-03): `SELECT name FROM learning_courses WHERE id = :courseId`
5. Last wrong answer (RAG-02): `SELECT q.text, a.text as correct_answer FROM learning_questions q JOIN learning_answers a ON a.question_id = q.id AND a.is_correct = true WHERE q.id = :questionId LIMIT 1`

**Done criteria:**
- Class exists with correct namespace `OCA\Learning\Service`
- buildContext() returns array matching the defined shape
- Token estimate capped at 4000 tokens by trimming questions
- No user PII in the returned array

### Task 2: Extend GeminiService::chat() with $ragContext parameter

type="auto"

**What:** Extend the `chat()` signature and inject RAG context into the system prompt.

Changes to `app/lib/Service/GeminiService.php`:

1. Signature change:
   ```php
   public function chat(string $rawInput, string $userId, array $ragContext = []): array
   ```

2. New private method `buildRagSystemAddendum(array $ragContext): string`:
   - Returns empty string if $ragContext is empty
   - Builds a compact text block like:
     ```
     Current learning context:
     Pool: {pool_name}
     Questions in this pool (sample): Q1: {text} | Answers: {a1}, {a2}...
     Leitner status: Box1={n}, Box2={n}, Box3={n}, Box4={n}, Box5={n}
     Course: {course_name}
     Last wrong question: "{question}" — correct answer was: "{correct_answer}"
     ```
   - Each section only added if the key is non-null/non-empty

3. In `buildSystemPrompt()`, append the RAG addendum at the end:
   ```php
   private function buildSystemPrompt(string $language, array $ragContext = []): string {
       $base = "You are VirtuProf...";
       $addendum = $this->buildRagSystemAddendum($ragContext);
       return $addendum !== '' ? $base . "\n\n" . $addendum : $base;
   }
   ```

4. Pass $ragContext through from chat() → buildSystemPrompt()

**Done criteria:**
- chat() accepts optional $ragContext array, defaults to []
- Empty $ragContext = no change to existing behaviour
- RAG data appears in system prompt when provided

### Task 3: Wire context into VirtuProfController::chat()

type="auto"

**What:** Update `VirtuProfController::chat()` to:

1. Accept optional parameters: `?int $poolId = null`, `?int $courseId = null`, `?int $lastWrongQuestionId = null`
2. Inject `RagContextService` via constructor
3. Build context before calling GeminiService:
   ```php
   $ragContext = $this->ragContextService->buildContext(
       $this->userId, $poolId, $courseId, $lastWrongQuestionId
   );
   $result = $this->geminiService->chat($message, $this->userId, $ragContext);
   ```

**Done criteria:**
- Controller accepts poolId, courseId, lastWrongQuestionId as optional POST params
- RagContextService injected and called before GeminiService
- Existing callers without these params continue to work (all params optional, default null)
