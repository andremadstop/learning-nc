<task type="auto">
  <name>Task 2: Add evaluateCommand() to cliStateMachine.js</name>
  <files>app/src/utils/cliStateMachine.js</files>
  <action>
Append export function evaluateCommand(cmd, domain, currentMode, context, commandOutputs) to cliStateMachine.js.

Return type: { type, nextMode, nextContext, lines }
- type: 'transition' | 'output' | 'error'
- nextMode: string (mode after this command)
- nextContext: object (updated context, e.g. { interface: 'Fa0/0' })
- lines: string[] (zero or more output lines to display in terminal)

Implementation order (evaluate in this exact sequence):

Step 1 - Static transition lookup:
  normalized = cmd.toLowerCase().trim()
  schema = DOMAIN_SCHEMAS[domain] || DOMAIN_SCHEMAS.generic
  modeTransitions = schema.transitions[currentMode] || {}
  if modeTransitions[normalized] exists:
    return { type: 'transition', nextMode: modeTransitions[normalized].toMode, nextContext: { ...context }, lines: [] }

Step 2 - Dynamic transition lookup (only if step 1 did not match):
  for each dt in (schema.dynamicTransitions || []):
    if dt.mode === currentMode:
      m = normalized.match(dt.pattern)
      if m:
        newContext = { ...context, [dt.contextKey]: dt.contextFn(m) }
        return { type: 'transition', nextMode: dt.toMode, nextContext: newContext, lines: [] }

Step 3 - command_outputs lookup (only if steps 1+2 did not match):
  outputs = commandOutputs || {}
  matchKey = Object.keys(outputs).find(k => k.toLowerCase() === normalized)
  if matchKey:
    outputText = outputs[matchKey]
    lines = outputText.split('\n')  -- split on literal newline chars
    return { type: 'output', nextMode: currentMode, nextContext: { ...context }, lines }

Step 4 - Error fallback:
  errorMsg = schema.errorMsg
  errText = typeof errorMsg === 'function' ? errorMsg(cmd.trim()) : errorMsg
  return { type: 'error', nextMode: currentMode, nextContext: { ...context }, lines: [errText] }

NOTE: nextMode and nextContext are ALWAYS returned so the caller can unconditionally update state.
context parameter may be undefined -- treat as {}.
commandOutputs parameter may be undefined -- treat as {}.
