**AuditCheckpointService** (`app/lib/Service/AuditCheckpointService.php`):

Inject via constructor: `KeyService $keyService`, `IDBConnection $db`, `IConfig $config`, `LoggerInterface $logger`.

`createCheckpoint(): void`:
1. Find the last checkpoint's `to_event_id` from `learning_audit_checkpoints` ORDER BY id DESC LIMIT 1. If none, use 0 as $lastToSeq.
2. Query learning_audit_events for MAX(seq_num) and its chain_hash WHERE seq_num IS NOT NULL. If MAX = null or MAX <= $lastToSeq: log debug "No new compliance events since last checkpoint" and return.
3. Count events: SELECT COUNT(*) FROM learning_audit_events WHERE seq_num BETWEEN $fromSeq AND $toSeq.
4. Build payload JSON (signing material — deterministic, no PII):
```php
$payload = json_encode([
    'typ'          => 'audit_checkpoint',
    'issuer'       => $this->keyService->hostDid(),
    'key_id'       => $material['key']->getKeyId(),
    'from_event_id' => $fromSeq,
    'to_event_id'   => $toSeq,
    'head_hash'     => $headHash,
    'event_count'   => $eventCount,
    'signed_at'     => time(),
], JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES | JSON_THROW_ON_ERROR);
```
5. Sign (NEVER use SigningService::sign()):
```php
$material = $this->keyService->getActiveSigningMaterial();
$secretKeyRaw = $material['secret'];
if (strlen($secretKeyRaw) !== SODIUM_CRYPTO_SIGN_SECRETKEYBYTES) {
    throw new \RuntimeException('Invalid Ed25519 secret key length');
}
$sigRaw = sodium_crypto_sign_detached($payload, $secretKeyRaw);
sodium_memzero($secretKeyRaw);
$sigHex = bin2hex($sigRaw);
```
6. INSERT into learning_audit_checkpoints: from_event_id=$fromSeq, to_event_id=$toSeq, head_hash=$headHash, event_count=$eventCount, signed_at=time(), key_id=$material['key']->getKeyId(), signed_payload=$payload, signature=$sigHex, anchor_url=NULL.
7. `$this->config->setAppValue('learning', 'last_checkpoint_at', (string)time());`
8. `$this->config->setAppValue('learning', 'last_checkpoint_to_event_id', (string)$toSeq);`

`getLivenessStatus(): array`:
- Read `last_checkpoint_at` from IConfig (default '0')
- Read `last_checkpoint_to_event_id` from IConfig (default '0')
- COUNT from learning_audit_events WHERE seq_num > $lastToEventId AND seq_num IS NOT NULL
- Return: `['last_checkpoint_at' => (int)$val, 'events_since_checkpoint' => $count, 'anchor_enabled' => $this->config->getAppValue('learning', 'forgejo_anchor_enabled', 'false') === 'true', 'last_anchor_status' => $this->config->getAppValue('learning', 'last_anchor_status', 'none'), 'is_overdue' => (time() - (int)$val) > (8 * 86400)]`

**AuditCheckpointJob** (`app/lib/BackgroundJob/AuditCheckpointJob.php`):

```php
class AuditCheckpointJob extends TimedJob {
    public function __construct(
        ITimeFactory $time,
        private AuditCheckpointService $service,
        private LoggerInterface $logger
    ) {
        parent::__construct($time);
        $this->setInterval(604800); // 7 days
    }
    protected function run($argument): void {
        try {
            $this->service->createCheckpoint();
        } catch (\Throwable $e) {
            $this->logger->warning(
                'AuditCheckpointJob failed: ' . $e->getMessage(),
                ['app' => 'learning']
            );
        }
    }
}
```
