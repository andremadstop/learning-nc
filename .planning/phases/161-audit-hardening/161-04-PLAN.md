`buildJsonl(array $filters): string` private method:
- Use QueryBuilder with the UNPREFIXED table name `learning_audit_events` (NC adds the `oc_` prefix
  automatically — never write `oc_learning_audit_events`, that double-prefixes to `oc_oc_...`):
  `$qb->select('seq_num','event_key','user_ref','context_json','created_at','chain_hash')`
  `   ->from('learning_audit_events')`
  `   ->where($qb->expr()->isNotNull('seq_num'))`
  date filters IN SQL: `[andWhere created_at >= :from_date] [andWhere created_at <= :to_date]`
  `   ->orderBy('seq_num','ASC')`
- **course_id filter is applied in PHP, NOT SQL** — a `LIKE '%"course_id":123%'` is fragile
  (it also matches 1234 and any other JSON key containing that substring). For each row, decode
  `$ctx = json_decode($row['context_json'], true)` and, if `$filters['course_id']` is set, SKIP the
  row unless `(int)($ctx['course_id'] ?? null) === (int)$filters['course_id']` (exact match).
- For each retained row: build output array WITHOUT user_id; add `course_id => $ctx['course_id'] ?? null`.
- Serialize: `json_encode($outRow, JSON_UNESCAPED_UNICODE | JSON_UNESCAPED_SLASHES) . "\n"` per row.
- Return concatenated string (fully deterministic given the same filters — same bytes = same sig).

`events(Request $request): DataDownloadResponse`:
1. assertAuditorOrDie()

3. $jsonl = $this->buildJsonl($filters)

`sig(Request $request): DataDownloadResponse`:
1. assertAuditorOrDie()
2. $jsonlBytes = $this->buildJsonl($filters) (regenerate — deterministic)
3. Sign inline (NOT via AuditCheckpointService):
```php
$material = $this->keyService->getActiveSigningMaterial();
$secretKeyRaw = $material['secret'];
if (strlen($secretKeyRaw) !== SODIUM_CRYPTO_SIGN_SECRETKEYBYTES) {
    throw new \RuntimeException('Invalid Ed25519 key length');
}
$sigRaw = sodium_crypto_sign_detached($jsonlBytes, $secretKeyRaw);
sodium_memzero($secretKeyRaw);
$sigHex = bin2hex($sigRaw);
```
4. return new DataDownloadResponse($sigHex . "\n", 'audit-events.sig', 'application/octet-stream')

`report(Request $request): DataDownloadResponse`:
1. assertAuditorOrDie()
2. Build $rows (same query as buildJsonl but as array for template)
3. Render templates/audit-export-print.php (pass $rows, $sha256 = hash('sha256', $this->buildJsonl($filters)), $sigHex)
4. return new DataDownloadResponse($html, 'audit-report.html', 'text/html')
