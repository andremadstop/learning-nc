# Phase 24 Plan 01: Note-Generator

## Objective

NoteGeneratorService generates Obsidian-compatible Markdown summaries for weak topics via Gemini,
writing them through LernbotFileService. NoteGeneratorController exposes the API endpoint.

Since Phase 23 (LernbotFileService) has not yet been executed, this plan also implements
LernbotFileService inline (covering FILES-01..05) as a dependency.

## Context

- @app/lib/Service/GeminiService.php — callGeminiApi() via private methods; note generation uses a dedicated method that bypasses the user-input 500-char limit (internal call, not user input)
- @app/lib/Service/LernprofilService.php — getWeakestTopics() provides pool_id + pool_name + error_rate + leitner_stats
- @app/lib/Service/RagContextService.php — loadPoolQuestions() pattern for question context
- @app/appinfo/routes.php — add note-generator route
- @app/lib/AppInfo/Application.php — DI wired automatically via NC autowiring

### Task 2: NoteGeneratorService
type="auto"

Implement `app/lib/Service/NoteGeneratorService.php`.

Core method: `generateSummary(string $userId, int $poolId, ?int $courseId = null): array`

Flow:
1. Load pool info (name, chapter_ref) from DB
2. Load top wrong question texts (up to 5) from learning_user_answers joined with learning_questions
3. Load error_rate from LernprofilService::getWeakestTopics()
4. Determine content_language from IConfig user setting
5. Build Gemini prompt (system + user, no PII — only pool_name, question texts, error_rate)
6. Call Gemini via dedicated private method `callGeminiForNote()` (bypasses user rate-limit, uses longer output: 800 tokens, temperature 0.5)
7. Ensure note starts with YAML frontmatter (validate/fix if missing)
8. Determine filename: slug of pool_name + `.md`
9. Write via LernbotFileService::writeNote() into /Zusammenfassungen/
10. Return ['path' => string, 'updated' => bool, 'content' => string]

System prompt template:
```
Du bist ein Lern-Assistent. Erstelle eine Zusammenfassung zum Thema "{pool_name}".

Format: Obsidian-kompatibles Markdown mit:
- YAML Frontmatter: created, source: VirtuProf, topic, status: '#schwach', chapter
- Kernpunkte als Bulletpoints (3-5 Punkte)
- Häufigster Fehler: basierend auf den häufig falsch beantworteten Fragen
- Übungsempfehlung mit Wiki-Links: [[Pool-{pool_name}]]
- Tags: #schwach #lernbot

Sprache: {language_name}
Max 500 Wörter. Nur Markdown, kein zusätzlicher Text davor oder danach.
```

`updateExistingNote(string $userId, int $poolId, ?int $courseId = null): array` — alias that calls generateSummary (filename = topic slug → overwrites existing, NOTE-04)

Done criteria:
- generateSummary() returns path, updated bool, content string
- Prompt contains NO userId/username/email
- Obsidian frontmatter included in output
- Wiki-links present in output (NOTE-03)
- updateExistingNote() calls generateSummary() transparently

### Task 3: NoteGeneratorController + Route
type="auto"

Implement `app/lib/Controller/NoteGeneratorController.php`:

```
POST /api/notes/generate
Body: { pool_id: int, course_id?: int }
Response: { path: string, updated: bool, content: string } | { error: string }
```

- `@NoAdminRequired`
- `#[UserRateLimit(limit: 3, period: 60)]` — Gemini calls are expensive
- Guards: pool must be accessible by user (check ownership or share or course membership)
- Returns 200 with note data, 400 on validation error, 503 if Gemini unavailable

Add route to `app/appinfo/routes.php`:
```php
['name' => 'noteGenerator#generate', 'url' => '/api/notes/generate', 'verb' => 'POST'],
```

Done criteria:
- Route registered
- Auth guard present
- Rate limit attribute applied
- Pool access verified before generation

### Task 4: Extend GeminiService with generateNote() method
type="auto"

Add `public function generateNote(string $systemPrompt, string $userPrompt): string` to GeminiService.php.

This method:

- Skips 500-char input sanitization

Done criteria:
