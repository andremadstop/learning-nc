    Create skillMapRenderer.js following the proven questMapRenderer.js pattern (pure D3 functions, no Vue coupling, D3 objects on instance properties):

    2. **createForceSimulation(nodes, links, width, height)** — D3 force simulation with:
       - forceLink (links, distance based on same-course vs cross-course)
       - forceManyBody (repulsion strength proportional to node radius)
       - forceCenter (center of viewport)
       - forceCollide (prevent overlap, radius + padding)
       - forceX/forceY with course-based clustering (nodes in same course attracted to same x-band)
    3. **setupZoom(svg, g, width, height)** — d3-zoom with scaleExtent [0.3, 3], translate extent, smooth transitions (reuse QuestMap zoom pattern)
    4. **renderNodes(g, nodes, onNodeClick)** — For each node:
       - Circle with fill = node.color, r = node.radius
       - Label (pool_name) below circle, font-size scales with radius
       - Trend indicator (symbol from getTrendIndicator) as small text above-right of circle
       - Cursor pointer, hover: slight scale + shadow
       - Click handler calls onNodeClick(node)
    5. **renderLinks(g, links)** — Lines connecting nodes within clusters, stroke: #ccc, opacity 0.4
    6. **updateSimulation(simulation, onTick)** — Wire simulation tick to update node/link positions
