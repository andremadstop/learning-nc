      - Question count
      - "Jetzt ueben" button — emits `openPool(poolId)` event
      - Close button

    **Script:**
    - Props: none (standalone view, fetches own data)
    - Data: `loading: true`, `error: null`, `selectedNode: null`, `pools: []`, `courses: []`
    - Mounted: fetch /api/profile/skill-map via axios, then call `_initGraph()`
    - `_initGraph()`:
      1. Call buildGraphData(this.pools) from skillMapEngine
      2. Call createSkillMap(this.$refs.skillMap, width, height) from skillMapRenderer
      3. Call renderLinks(g, graphData.links)
      4. Call renderNodes(g, graphData.nodes, this.onNodeClick)
      5. Call createForceSimulation(graphData.nodes, graphData.links, width, height)
      6. Call setupZoom(svg, g, width, height)
      7. Wire simulation tick to update positions
      8. Store all D3 objects on this._ (NOT reactive data)
    - `onNodeClick(node)`: Set this.selectedNode = node
    - `closeSidebar()`: Set this.selectedNode = null
    - `startPractice()`: Emit 'openPool' with selectedNode.id
    - BeforeDestroy: Stop simulation if running (this._simulation?.stop())
    - Use ResizeObserver to re-render on container resize

    **Import skill-map.css in main.js** (following ghostline.css pattern):
    ```javascript

    ```

    **Responsive:** Width/height from container element dimensions, not hardcoded. Min-height 400px via CSS.
