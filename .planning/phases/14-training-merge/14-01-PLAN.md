Aus SwipeMode.vue — Swipe-Logik die zu übernehmen ist:
```js
// data()
cardAnimClass: '',   // 'card-enter' beim Karten-Wechsel
canDrag: false,      // erst true nach showFeedback
isDragging: false,
pointerDown: false,
dragStartX: 0, dragStartY: 0, dragDeltaX: 0,
showFeedback: false, // Feedback-Overlay sichtbar

// computed
cardDragStyle() {
  if (this.dragDeltaX === 0) return {};
  const x = this.dragDeltaX;
  const rotate = Math.min(Math.max(x * 0.06, -15), 15);
  const opacity = Math.max(0.4, 1 - Math.abs(x) / 500);
  return { transform: 'translateX(' + x + 'px) rotate(' + rotate + 'deg)', opacity: String(opacity) };
}

// Pointer-Handler: onPointerDown / onPointerMove / onPointerUp
// Threshold: Math.abs(dragDeltaX) > 80 → flyOut → goToNext
```

**1. data() erweitern:**

**2. Toggle in der Start-Ansicht (`.training-start`):**
Vor dem Start-Button einen Toggle hinzufügen:
```html
<div class="mode-toggle" role="group" :aria-label="t('learning', 'Lernmodus')">
  <button class="mode-toggle-btn" :class="{ active: !wfMode }" @click="wfMode = false">
    Multiple-Choice
  </button>
  <button class="mode-toggle-btn" :class="{ active: wfMode }" @click="wfMode = true">
    Wahr/Falsch
  </button>
</div>
```

**3. Wahr/Falsch-Kartenblock in `.training-active`:**
Direkt nach dem `<div class="question-card">` eine NEUE bedingte Sektion für wfMode einfügen. Diese ersetzt (per `v-if`) den bestehenden `.question-card`-Block wenn `wfMode && !showResults` aktiv ist. Der bestehende `.question-card`-Block bekommt `v-if="!wfMode"`.

Der WF-Block enthält:
- `.card-stack` Wrapper mit `touch-action: pan-y`
- `.swipe-card` div mit `:class="[cardAnimClass, { 'card-dragging': isDragging }]"`, `:style="cardDragStyle"`, `@pointerdown/pointermove/pointerup/pointercancel` Events
- `.feedback-overlay` mit `v-if="showFeedback && !isDragging"` (grün/rot mit ✓/✗-Icon)
- Fragetext + optionales Bild (identisch wie im MC-Block)
- Erklärungs-Bereich nach Antwort (explanation + instructor_note)

**4. True/False-Buttons unter der Karte (wenn !showFeedback):**
```html
<div v-if="!showFeedback" class="wf-buttons">
  <button class="wf-btn wf-true" @click="selectWfAnswer(true)" :disabled="submitting">
    ✓ {{ t('learning', 'Wahr') }}
  </button>
  <button class="wf-btn wf-false" @click="selectWfAnswer(false)" :disabled="submitting">
    ✗ {{ t('learning', 'Falsch') }}
  </button>
</div>
<div v-if="showFeedback" class="swipe-hint-area">
  <p class="swipe-hint">← {{ t('learning', 'Wischen oder weiter tippen') }} →</p>
  <NcButton type="primary" @click="advanceWfCard">
    {{ currentIndex < questions.length - 1 ? t('learning', 'Weiter →') : t('learning', 'Ergebnisse') }}
  </NcButton>
</div>
```

**5. Methods hinzufügen:**

`selectWfAnswer(isTrue)` — findet die korrekte Antwort in `currentQuestion.answers` (is_correct===true → Wahr, false → Falsch), ruft dann `submitAnswer(answerId)` auf und setzt danach `showFeedback = true`, `canDrag = true`, `cardAnimClass = ''`.

WICHTIG: Die Wahr/Falsch-Logik mappt auf die bestehende `submitAnswer(answerId)` Methode. Wenn isTrue=true wird die Antwort mit `is_correct === true` als answerId genommen, wenn isTrue=false die mit `is_correct === false`. Falls die Antworten noch nicht vorhanden (leeres Array), `skipQuestion()` aufrufen.

`advanceWfCard()` — setzt `dragDeltaX = window.innerWidth + 100`, `canDrag = false`, nach 380ms `goToWfNext()`.

`goToWfNext()` — wie SwipeMode.goToNext(): resettet showFeedback, selectedAnswerId, dragDeltaX, canDrag, isDragging. Dann `currentIndex++`. Wenn currentIndex < questions.length: `$nextTick(() => { cardAnimClass = 'card-enter' })`. Sonst `completeSession()`.

`onPointerDown/Move/Up` — identisch aus SwipeMode übernehmen. onPointerUp: wenn `Math.abs(dragDeltaX) > 80` und `canDrag`, dann flyOut (dragDeltaX auf ±(innerWidth+100)) + `setTimeout(goToWfNext, 350)`.

**6. Watcher auf `wfMode`:**
```js
wfMode(newVal) {

  if (this.session) {
    this.restartTraining();
  }
}
```

**7. restartTraining() erweitern:**
Alle WF-spezifischen State-Felder zurücksetzen: `cardAnimClass = ''`, `canDrag = false`, `isDragging = false`, `dragDeltaX = 0`, `showFeedback = false`.
