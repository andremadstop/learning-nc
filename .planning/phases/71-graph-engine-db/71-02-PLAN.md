Modify `StoryEngineService.php` to detect and delegate graph campaigns to CampaignGraphService. Changes:

1. **Constructor**: Add `CampaignGraphService $graphService` as new DI parameter. Store as `private CampaignGraphService $graphService`. NC 30 auto-wires this — no Application.php changes needed.

2. **validateCampaignStructure()**: Currently requires `scenes` field. Change to:
   - If `isset($data['graph']['nodes'])` AND `isset($data['graph']['edges'])`: validate graph structure instead
     - Each node must have `id` field
     - Each edge must have `id`, `from`, `to` fields
     - All edge `from`/`to` must reference existing node IDs
   - Else: require `scenes` as before (existing validation unchanged)
   - Campaigns MAY have BOTH `scenes` and `graph` — graph takes priority at runtime

3. **startCampaign()**: After `$campaign = $this->loadCampaign($campaignId)`, add:
   ```php
   if ($this->graphService->isGraphCampaign($campaign)) {
       $this->validateCharacterClass($characterClass);
       $result = $this->graphService->initGraphSession(
           $userId, $campaignId, $characterClass, $campaign['graph']
       );
       // Transform result to match existing API shape:
       // { progress: {...}, scene: {node data + available_edges as choices} }
       return $this->transformGraphResponse($result, $campaign);
   }
   ```
   Keep ALL existing linear logic after this early return — zero changes to linear path.

4. **getScene()**: After loading campaign, add:
   ```php
   if ($this->graphService->isGraphCampaign($campaign)) {
       $result = $this->graphService->getGraphScene($userId, $campaignId, $campaign['graph']);
       return $this->transformGraphResponse($result, $campaign);
   }
   ```

5. **makeChoice()**: After loading campaign, add:
   ```php
   if ($this->graphService->isGraphCampaign($campaign)) {
       // In graph mode, choiceId = edge ID
       $result = $this->graphService->traverseEdge(
           $userId, $campaignId, $choiceId, $campaign['graph'], $campaign
       );
       return $this->transformGraphResponse($result, $campaign);
   }
   ```

6. **New private method** `transformGraphResponse(array $graphResult, array $campaign): array`:
   - Maps CampaignGraphService response to the shape StoryController/frontend expects:
   ```php
   private function transformGraphResponse(array $graphResult, array $campaign): array {
       $node = $graphResult['node'];
       $edges = $graphResult['available_edges'] ?? [];
       $state = $graphResult['state'];

       // Map edges to choices format the frontend understands
       $choices = array_map(fn(array $edge) => [
           'id' => $edge['id'],
           'text' => $edge['label'] ?? $edge['id'],
           'skill_check' => null, // Phase 73 will add simulator refs
       ], $edges);

       return [
           'progress' => [
               'campaign_id' => $state['campaign_id'] ?? '',
               'current_scene_id' => $state['graph_position'] ?? '',
               'character_class' => $state['character_class'] ?? 'helpdesk',
               'score' => $state['score'] ?? 0,
               'status' => $state['status'] ?? 'in_progress',
               'state_bag' => $state['state_bag_decoded'] ?? [],
           ],
           'scene' => [
               'id' => $node['id'],
               'title' => $node['title'] ?? $node['id'],
               'narrative' => $node['narrative'] ?? '',
               'choices' => $choices,
               'act' => $node['act'] ?? $state['act_number'] ?? 1,
               'is_ending' => empty($edges) && ($node['is_ending'] ?? false),
               'characters' => $node['characters'] ?? [],
               'simulation' => $node['simulation'] ?? null,
               'graph_mode' => true,
           ],
       ];
   }
   ```

**Critical: Do NOT change any existing linear-mode logic.** The graph branches are early-return guards — all code below them remains untouched. This ensures the 20 existing campaigns work exactly as before.
