<task type="auto">
  <name>Task 2: CampaignGraphService — graph traversal, state-bag, conditions</name>
  <files>app/lib/Service/CampaignGraphService.php</files>
  <action>
Create `app/lib/Service/CampaignGraphService.php` in namespace `OCA\Learning\Service`.

**Constructor DI:**
- `CampaignStateMapper $stateMapper`
- `LoggerInterface $logger`

**Core public methods:**

1. `isGraphCampaign(array $campaignData): bool`
   - Returns `true` if `isset($campaignData['graph']['nodes'])` AND `isset($campaignData['graph']['edges'])`
   - This is the detection method StoryEngineService will call in Plan 02

2. `getStartNodeId(array $graph): string`
   - Returns the ID of the node with `"start": true` flag, or the first node in the array
   - Throws RuntimeException if graph has no nodes

3. `findNode(array $graph, string $nodeId): array`
   - Linear scan of `$graph['nodes']` by `id` field
   - Throws RuntimeException if not found

4. `getAvailableEdges(array $graph, string $fromNodeId, array $stateBag): array`
   - Filter `$graph['edges']` where `from === $fromNodeId`
   - For each edge, evaluate conditions via `evaluateConditions($edge['conditions'] ?? [], $stateBag)`
   - Return only edges where ALL conditions pass
   - Each returned edge includes: `id`, `from`, `to`, `label` (display text), `conditions` (for transparency)

5. `evaluateConditions(array $conditions, array $stateBag): bool`
   - Empty conditions = always true
   - Supported condition types:
     - `requires_flag` (string): `$stateBag['flags'][$flag] ?? false` must be truthy
     - `requires_item` (string): `in_array($item, $stateBag['items'] ?? [])`
     - `min_reputation` (assoc array): For each `{domain: value}`, `($stateBag['reputation'][$domain] ?? 0) >= $value`
     - `max_reputation` (assoc array): For each `{domain: value}`, `($stateBag['reputation'][$domain] ?? 0) <= $value`
     - `requires_class` (string): checked externally, skip in this method (Plan 02/Phase 73 concern)
   - All conditions must pass (AND logic)

6. `applyEffects(array $effects, array $stateBag): array`
   - Returns NEW state-bag (immutable pattern, do not mutate input)
   - Supported effect types:
     - `set_flag` (string): `$bag['flags'][$flag] = true`
     - `remove_flag` (string): `unset($bag['flags'][$flag])`
     - `add_item` (string): append to `$bag['items']` if not already present
     - `remove_item` (string): remove from `$bag['items']`
     - `add_reputation` (assoc array): For each `{domain: delta}`, `$bag['reputation'][$domain] = ($bag['reputation'][$domain] ?? 0) + $delta`
   - Deep-copy the input state-bag before modifying (use `json_decode(json_encode($stateBag), true)`)

7. `traverseEdge(string $userId, string $campaignId, string $edgeId, array $graph, array $campaignData): array`
   - Load CampaignState from mapper (throw if not found)
   - Find the edge by ID in `$graph['edges']`
   - Validate edge.from === current graph_position
   - Validate conditions pass against current state_bag
   - Find target node
   - Apply node's `effects` (if any) to state_bag via `applyEffects()`
   - Update CampaignState: graph_position = edge.to, state_bag = updated bag, act_number from target node if present, updated_at = time()
   - Save via mapper->update()
   - Return `['state' => serialized CampaignState, 'node' => target node data, 'available_edges' => getAvailableEdges for new position]`

8. `initGraphSession(string $userId, string $campaignId, string $characterClass, array $graph): array`
   - Delete existing CampaignState for user+campaign if any
   - Create new CampaignState with graph_position = getStartNodeId(), empty state_bag `{flags:{},items:[],reputation:{}}`, act_number = 1
   - Apply start node effects if any
   - Save via mapper->insert()
   - Return same format as traverseEdge

9. `getGraphScene(string $userId, string $campaignId, array $graph): array`
   - Load CampaignState, find current node, return node + available edges + state

**Private helper:**
- `serializeState(CampaignState $state): array` — returns associative array with all fields for JSON response

**Important implementation notes:**
- Use `declare(strict_types=1)` at top
- All string comparisons with `===`
- Log warnings on invalid conditions/effects (do not throw — graceful degradation)
- No dependency on GeminiService or StoryEngineService (this class is standalone)
- NC DI will auto-wire this class — no manual registration needed in Application.php (NC 30 auto-wiring)
