<task type="auto">
  <name>Task 2: PbqAuthorTool.vue — subtype selector + per-subtype forms + computed JSON</name>
  <files>app/src/components/PbqAuthorTool.vue</files>
  <action>
    Create app/src/components/PbqAuthorTool.vue as a standalone SFC. It is not yet wired into the app (Plan 02 does that). It receives no props for v1 — all state is internal.

    Component structure:

    IMPORTS:
    - NcButton from '@nextcloud/vue/dist/Components/NcButton.js'
    - { DOMAIN_SCHEMAS } from '../utils/cliStateMachine.js'
    - { DEVICE_ICONS } from '../utils/networkTopologyIcons.js'
    Do NOT import PbqRenderer here — that is Plan 02's job.

    DATA:
    ```javascript
    selectedSubtype: 'cli',
    copySuccess: false,
    showJsonFallback: false,

    cliForm: {
      domain: 'cisco_ios',
      hint: '',
      terminals: [{ name: 'Router' }],
      commandOutputs: [{ cmd: '', output: '' }],  // array of {cmd, output} — converted to dict in computed
    },

    placementForm: {
      useTopology: true,
      scoringMode: 'strict',
      positions: [{ id: 'n1', label: '', correct: '' }],
      deviceOptions: ['router', 'switch', 'firewall', 'server'],
    },

    topologyForm: {
      nodes: [{ id: 'n1', type: 'router', label: '', x: 200, y: 150 }],
      links: [],
    },

    dropdownForm: {
      questions: [{ id: 'q1', label: '', options: ['', ''], correct: '' }],
    },

    cableForm: {
      rawJson: '',
    },
    ```

    COMPUTED:
    - validDomains() → Object.keys(DOMAIN_SCHEMAS)
    - validDeviceTypes() → Object.keys(DEVICE_ICONS)
    - generatedConfig() — switch on selectedSubtype:
      - 'cli': { domain, hint: hint||undefined, terminals: cliForm.terminals, command_outputs: cliForm.commandOutputs reduced to dict with keys lowercased and empty pairs filtered }
      - 'placement': { positions, device_options: placementForm.deviceOptions, scoring_mode, topology: (placementForm.useTopology && topologyForm.nodes.length > 0) ? {nodes: topologyForm.nodes, links: topologyForm.links} : null }
      - 'dropdown': { questions: dropdownForm.questions }
      - 'cable': try { return JSON.parse(cableForm.rawJson) } catch { return {} }
      - 'multi_panel': { cli: {domain: cliForm.domain, terminals: cliForm.terminals, command_outputs: ...same as cli}, placement: {positions: placementForm.positions, device_options: placementForm.deviceOptions, scoring_mode: placementForm.scoringMode}, topology: topologyForm.nodes.length > 0 ? {nodes: topologyForm.nodes, links: topologyForm.links} : null }
      - default: {}
    - generatedJson() → JSON.stringify({ pbq_subtype: selectedSubtype, pbq_config: generatedConfig }, null, 2)

    METHODS:
    - async copyJson() { try { await navigator.clipboard.writeText(generatedJson); this.copySuccess=true; setTimeout(()=>{this.copySuccess=false},2000) } catch { this.showJsonFallback=true } }
    - addTerminal() { this.cliForm.terminals.push({ name: '' }) }
    - removeTerminal(i) { this.cliForm.terminals.splice(i, 1) }
    - addCommandOutput() { this.cliForm.commandOutputs.push({ cmd: '', output: '' }) }
    - removeCommandOutput(i) { this.cliForm.commandOutputs.splice(i, 1) }
    - addPosition() { const id = 'n' + (this.placementForm.positions.length + 1); this.placementForm.positions.push({ id, label: '', correct: '' }) }
    - removePosition(i) { this.placementForm.positions.splice(i, 1) }
    - addNode() { const id = 'n' + (this.topologyForm.nodes.length + 1); this.topologyForm.nodes.push({ id, type: 'router', label: '', x: 200, y: 150 }) }
    - removeNode(i) { this.topologyForm.nodes.splice(i, 1) }
    - addLink() { this.topologyForm.links.push({ from: '', to: '' }) }
    - removeLink(i) { this.topologyForm.links.splice(i, 1) }
    - addDropdownQuestion() { const id = 'q' + (this.dropdownForm.questions.length + 1); this.dropdownForm.questions.push({ id, label: '', options: ['', ''], correct: '' }) }
    - removeDropdownQuestion(i) { this.dropdownForm.questions.splice(i, 1) }
    - addDropdownOption(qi) { this.$set(this.dropdownForm.questions[qi], 'options', [...this.dropdownForm.questions[qi].options, '']) }

    TEMPLATE layout (no v-html anywhere):
    1. <div class="pbq-author-tool">
    2. Section: subtype selector — <select v-model="selectedSubtype"> with 5 options
    3. v-if="selectedSubtype === 'cli'" — CLI section: domain select (from validDomains), hint input, terminals array editor, command_outputs array editor
    4. v-if="selectedSubtype === 'placement'" — Placement section: positions array editor (id/label/correct fields), scoring_mode select, device_options checkboxes (from validDeviceTypes), topology toggle + node/link editors
    5. v-if="selectedSubtype === 'dropdown'" — Dropdown section: questions array editor (label, options array, correct)
    6. v-if="selectedSubtype === 'cable'" — Cable section: <textarea v-model="cableForm.rawJson"> with placeholder showing expected JSON shape
    7. v-if="selectedSubtype === 'multi_panel'" — Multi-panel: reuse CLI + topology sections (same v-model bindings)
    8. JSON output section: <pre class="author-json-output">{{ generatedJson }}</pre> (no v-html)
    9. Copy button: <NcButton @click="copyJson">{{ copySuccess ? 'Kopiert!' : 'JSON kopieren' }}</NcButton>
    10. Fallback textarea v-if="showJsonFallback": <textarea readonly :value="generatedJson"> for manual copy

    CSS: .pbq-author-tool scoped, .author-section margin-bottom 20px, .author-array-row display flex gap 8px, .author-json-output font-family monospace font-size 12px white-space pre-wrap background var(--color-background-dark) padding 12px border-radius 6px max-height 300px overflow-y auto

    Vue 2 reactivity rules:
    - All array mutations via push/splice (reactive by default)
    - All nested object property sets via this.$set(arr[i], 'field', value)
    - Never direct index assignment like arr[i].field = value for new keys
