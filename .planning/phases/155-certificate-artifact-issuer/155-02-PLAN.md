KeyService (autowired — constructor takes CertKeyMapper, EncryptionService, IURLGenerator):
  - init(): CertKey — guard !extension_loaded('sodium') → throw. If an 'active' key already exists, throw
    (instruct admin to use --rotate). Generate sodium_crypto_sign_keypair(); derive 32B public + 64B secret;
    keyId = base64url(public); publicKeyB64u = base64url(public); secretKeyEnc = EncryptionService.encrypt(base64(secret));
    insert; sodium_memzero(secret). Return CertKey.
  - rotate(): CertKey — set current active CertKey.status='retired' (update, never delete), then init a new active key.
  - getActiveSigningMaterial(): array{key: CertKey, secret: string} — decrypt active key; HARD-ERROR if the
    decrypted bytes are not a valid 64-byte Ed25519 secret key (defeat the plaintext fallback). Used by 155-04.
  - hostDid(): string — 'did:web:' . parse_url($urlGenerator->getBaseUrl(), PHP_URL_HOST) . ':apps:learning'.
