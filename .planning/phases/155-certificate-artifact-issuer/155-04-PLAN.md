IssuanceService (autowired; deps: CertificateMapper, SigningService, KeyService, INotificationManager,
  IThemingDefaults, ITimeFactory/time(), IURLGenerator, LoggerInterface):
  - issueIfPassed(string $userId, int $courseId, PassResult $result): ?Certificate
    - if !$result->passed → return null.
    - idempotency: findByUserAndCourse($userId,$courseId); if a non-revoked row exists → return it (NO re-issue).
    - verification_id = UUIDv4 from random_bytes(16) (format by hand — no ext-uuid).
    - build OB3 credential array (RESEARCH "OB3 skeleton"): @context [vc v2, ob3 context-3.0.3], id urn:uuid:<vid>,
      type [VerifiableCredential, OpenBadgeCredential], issuer {id: did:web:<host>:apps:learning, type:[Profile],
      name: IThemingDefaults.getName(), image:{id:<absolute themed logo URL>, type:Image}},
      validFrom (ISO8601 issued_at), validUntil (ISO8601 expires_at — OMIT if null),
      credentialSubject {type:[AchievementSubject], achievement {id, type:[Achievement], name:<course title frozen>,
      description, criteria:{narrative:"Passed with score ≥ <threshold>% (lucky guesses excluded)."}},
      result:[{type:[Result], resultDescription:"score:<score>; threshold:<threshold>"}]}.
      DSGVO: identifier = display name only, NO plaintext email.
    - [$key,$secret] = KeyService.getActiveSigningMaterial(); $jwt = SigningService.sign($credential, $key, $secret); sodium_memzero($secret).
    - persist Certificate (verificationId, userId, courseId, keyId=$key->getKeyId(), credentialJson=$jwt, revoked=false, issuedAt, expiresAt).
    - fire notification (see Task 2) deduped; return Certificate.
