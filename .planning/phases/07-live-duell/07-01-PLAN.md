  <behavior>
    - createDuel(poolId, userId): selects 10 random TRUE/FALSE questions from pool, generates unique 6-char alphanumeric code (retry on collision), creates session with status='waiting', returns session state
    - joinDuel(code, userId): validates code exists, status='waiting', userId != creator_uid, sets opponent_uid, updates status='ready', returns session state. Error if already has opponent.
    - setReady(code, userId): sets creator_ready or opponent_ready. When both true, updates status='active', returns session state.
    - getState(code, userId): validates userId is creator or opponent. Updates creator_last_poll or opponent_last_poll. Checks for abandoned opponents (last_poll > 30s ago, status active/ready) → mark expired, set winner. Returns full state including question text+answers for current_question_index, both scores, status.
    - submitAnswer(code, userId, answerCorrect, answeredAt): validates session active, question index matches, player hasn't answered yet. Inserts DuelAnswer. If both answered: apply scoring matrix, update scores, increment current_question_index (or set status='finished' if index reaches 10). Returns updated state.
    - rematch(code, userId): validates finished session, userId is creator or opponent. Creates NEW session with same pool, same players (original creator stays creator), new random 10 questions, new code. Returns new session code.

    Scoring matrix (LOCKED — from CONTEXT.md):
    - A correct first, B wrong: A=+4, B=0
    - A wrong, B correct first: A=0, B=+4
    - Both correct (A faster answeredAt): A=+3, B=+2
    - Both correct (equal answeredAt): A=+3, B=+3
    - Both wrong (any order): A=-1, B=-1

    "First" = lower answeredAt millisecond timestamp. "Equal" = answeredAt within 50ms of each other.

    getState must only return question data for the CURRENT question (not all 10) to prevent cheating.

    Only TRUE/FALSE questions selected: filter pool questions where question type is 'true_false' or where answers contain exactly one correct boolean answer. Fallback: select any question type if pool has fewer than 10 true/false questions (use whatever is available).
  </behavior>
