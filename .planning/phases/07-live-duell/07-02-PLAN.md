  <action>
    Create DuelMode.vue as a Vue 2.7 SFC with these UI phases controlled by computed `phase`:

    **Phase: 'join'** (initial — user hasn't created or joined a duel)
    - "Duell" heading
    - Pool selector `<select>` populated from GET /api/pools (load on mounted)
    - Code input field (placeholder "Duell-Code eingeben") with "Beitreten" button
    - "Neues Duell erstellen" primary button (requires pool selected)
    - Back button emitting @back
    - Error display via NcNoteCard type="error"

    **Phase: 'lobby'** (duel created or joined, waiting for opponent / ready state)
    - Show the duel code prominently with a "Code kopieren" button (navigator.clipboard.writeText)
    - Show opponent_uid if joined, else "Warte auf Gegner..." message
    - Show ready status: creator_ready / opponent_ready as checkmarks
    - "Bereit!" NcButton (primary) — calls POST ready, disabled after clicked
    - "Abbrechen" button emitting @back (clears polling)
    - Status message: "Warte bis beide bereit sind..."

    **Phase: 'question'** (status === 'active' and not yet answered current question)
    - Progress bar: current_question_index / 10
    - Score display: `{my_score} : {opponent_score}` — resolve my_role to get correct score
    - Question text in large card (similar to SwipeMode card styling)
    - If current_question.image_path: show image above text
    - Two big buttons side-by-side: "Wahr" (calls onAnswer(true)) and "Falsch" (calls onAnswer(false))
    - Buttons disabled after clicking (prevent double-submit)
    - "Warte auf Gegner..." overlay text if answered but opponent hasn't yet (show when hasAnswered but state still same question)

    **Phase: 'feedback'** (both answered — show result for ~1.5s before next question auto-advances)
    - Show: answered correctly or not (green/red visual)
    - Show points earned this round (from last answer response)
    - Show updated scores: creator_score : opponent_score
    - Auto-advance: after 1500ms, clear feedback and resume polling (next question will appear)

    **Phase: 'finished'** (status === 'finished')
    - "Duell beendet!" heading
    - Final scores: creator_uid (score) vs opponent_uid (score)
    - Winner announcement: "Du hast gewonnen!" or "Gegner gewinnt" or "Unentschieden!"
    - "Rematch" NcButton (primary) — calls POST rematch, then sets new code and resets to lobby phase
    - "Zurück" NcButton — emits @back

    **Phase: 'expired'** (status === 'expired')
    - "Duell abgebrochen" message
    - Explanation: "Ein Spieler hat die Verbindung verloren."
    - "Zurück" button

    **Data:**
    ```js
    data() {
      return {
        phase: 'join',       // join|lobby|question|feedback|finished|expired
        duelCode: '',        // active duel code
        joinCode: '',        // v-model for join input
        duelState: null,     // full state from API
        pools: [],
        selectedPoolId: 0,
        loading: false,
        error: null,
        pollingInterval: null,
        hasAnswered: false,  // true after onAnswer() called, reset on new question
        lastPoints: 0,       // points from last answer, shown in feedback phase
        answeredCorrect: false,
      }
    }
    ```

    **Computed:**
    ```js
    myRole() { return this.duelState?.my_role },
    myScore() {
      if (!this.duelState) return 0;
      return this.duelState.my_role === 'creator' ? this.duelState.creator_score : this.duelState.opponent_score;
    },
    opponentScore() {
      if (!this.duelState) return 0;
      return this.duelState.my_role === 'creator' ? this.duelState.opponent_score : this.duelState.creator_score;
    },
    opponentUid() { return this.duelState?.opponent_uid || null },
    currentQuestion() { return this.duelState?.current_question || null },
    ```

    **Polling logic:**
    - startPolling(): `this.pollingInterval = setInterval(this.pollState, 500)`
    - stopPolling(): `clearInterval(this.pollingInterval); this.pollingInterval = null`
    - pollState(): GET /api/duels/{code}/state → update duelState → detect phase transitions:
      - If status changes to 'active' and hasAnswered → stay in 'question' phase (opponent still thinking)
      - If current_question_index increments → reset hasAnswered, set phase='question'
      - If status === 'finished' → stopPolling, phase='finished'
      - If status === 'expired' → stopPolling, phase='expired'
    - destroyed(): stopPolling()

    **onAnswer(correct):**
    1. Set hasAnswered=true, disable buttons
    2. POST /api/duels/{code}/answer with { answerCorrect: correct, answeredAt: Date.now() }
    3. On response: extract points_earned from response (compute from score delta), set lastPoints, answeredCorrect=correct
    4. If response status === 'finished': stopPolling, phase='finished'
    5. Else if both answered (poll returns new question_index): phase='question', reset hasAnswered
    6. Else: poll loop handles advancement

    Note: To compute lastPoints from the state delta, track previous score before submitting. Alternatively, the feedback phase simply shows "Richtig! +" or "Falsch" without exact points (simpler). Use simple: if answeredCorrect and state.current_question_index > previous_index → show "+3 oder +4" etc. Keep it simple: just show green/red + updated total score in feedback.

    Style using NC CSS variables. Buttons use NcButton with type="primary"/"secondary". Card styling similar to SwipeMode's .swipe-card class (box-shadow, border-radius, padding). Progress via NcProgressBar.
