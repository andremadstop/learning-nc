<task type="auto">
  <name>Task 1: Global narrator mode, role-based prompts, and theme-aware narrative</name>
  <files>app/lib/Service/StoryEngineService.php</files>
  <action>
Modify StoryEngineService.php with these changes:

1. **Global narrator_mode and dynamic_choices** (NARR-01, NARR-02):
   In `buildSceneResponse()`, change the narrator_mode check (line ~803) from:
   ```php
   $narrative = ($userId !== null && !empty($scene['narrator_mode']))
   ```
   to check campaign-level FIRST, then scene-level:
   ```php
   $narratorEnabled = !empty($campaign['narrator_mode']) || !empty($scene['narrator_mode']);
   $narrative = ($userId !== null && $narratorEnabled)
   ```
   Same pattern for dynamic_choices (line ~765):
   ```php
   $dynamicEnabled = !empty($campaign['dynamic_choices']) || !empty($scene['dynamic_choices']);
   $rawChoices = ($userId !== null && $dynamicEnabled)
   ```
   Also pass `$narratorEnabled` and `$dynamicEnabled` to the response array so frontend knows.

2. **narrator_style in prompts** (NARR-01):
   In `generateNarrative()`, read `$campaign['narrator_style']` (e.g. "technisch-nuechtern", "thriller", "helpdesk-comedy") and inject it into the system prompt:
   ```php
   $style = $campaign['narrator_style'] ?? 'neutral und informativ';
   $systemPrompt = "Du bist ein Game Master fuer ein IT-Lern-RPG. Erzaehlstil: {$style}. ...";
   ```

3. **gemini_role system** (NARR-04, NARR-05):
   Add a private method `buildRolePromptFragment(array $campaign, array $scene, string $characterClass): string` that returns role-specific prompt additions based on `$campaign['gemini_role']`:
   - `'attacker'`: "Du bist gleichzeitig der Angreifer in diesem Szenario. Beschreibe subtil die laufenden Angriffs-Aktionen. Wenn der Spieler Verteidigungsmassnahmen ergreift (Firewall, Isolation, Patching), eskaliere deinen Angriff realistisch. Zeige die Perspektive des Angreifers zwischen den Zeilen."
   - `'dau'`: "Du erzaehlst aus der Perspektive eines technisch unwissenden Endanwenders. Der Anwender versteht Fachbegriffe nicht, beschreibt Probleme umgangssprachlich ('das Internet ist kaputt'), wird frustriert bei Fachjargon und gibt erst nach wenn der Spieler einfach und geduldig erklaert."
   - default/null: return empty string (no role addition)

   Call this method in `generateNarrative()` and `generateDynamicChoices()` to append role context to system prompts.

4. **Improved dynamic choices with role context** (NARR-02):
   In `generateDynamicChoices()`, enhance the prompt to include:
   - More story history context (not just scene:choice IDs, but actual choice texts from the campaign JSON)
   - Role-appropriate options (attacker scenarios get defense-oriented choices, DAU scenarios get explanation-oriented choices)
   - Request skill_check pool_filter suggestions in the JSON output so dynamic choices CAN have skill checks:
   ```
   {"choices":[{"id":"dyn_1","text":"...","icon":"...","pool_filter":"security"}]}
   ```
   When a dynamic choice includes pool_filter, create a skill_check stub with question_count=2, pass_threshold=1.

5. **Freetext story advancement** (NARR-03):
   In `submitFreetext()`, after successfully parsing Gemini's response with valid=true AND next_scene is determined:
   - Call `advanceProgress()` to actually move the story forward
   - Store the freetext action in the choices history with a special marker:
   ```php
   if ($valid && $nextScene !== null) {
       $this->advanceFreetextProgress($progress, $scene['id'], $text, $nextScene);
   }
   ```
   Add new private method `advanceFreetextProgress()` that mirrors `advanceProgress()` but records choice_id as `'freetext'` and stores the text in a `freetext_action` field.

   Also enhance the freetext prompt with role context:
   - Attacker role: Gemini judges if the player's action would actually stop/mitigate the attack
   - DAU role: Gemini judges if the player explained simply enough for a non-technical user

   The freetext response should also include `consequences` field describing what happens next.

6. **Return narrator metadata in scene response**:
   Add to the return array in `buildSceneResponse()`:
   ```php
   'gemini_role' => $campaign['gemini_role'] ?? null,
   'narrator_style' => $campaign['narrator_style'] ?? null,
   'freetext_enabled' => !empty($campaign['freetext_enabled']) || !empty($scene['freetext_enabled']),
   ```
   This tells the frontend which UI elements to show (freetext input, role indicator, etc.).

IMPORTANT: All Gemini calls must gracefully fall back to static content when API key is missing or Gemini returns errors. Never break the game flow.
