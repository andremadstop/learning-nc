**TrainingMode.vue:**

Add a watcher on `currentIndex` (or `currentQuestion` — whichever drives the displayed question) that emits question context. Find the existing `currentQuestion` computed property or data reference. Add a watcher:

```javascript
watch: {
  currentQuestion: {
    handler(q) {
      if (!q) return
      this.$root.$emit('virtuprof:context', {
        poolId: this.poolId,
        courseId: this.courseId,
        questionContext: {
          questionText: q.text || q.question || '',
          answers: (q.answers || []).map(a => a.text || a),
          correctAnswerIndex: this.getCorrectAnswerIndex(q),
          explanation: q.explanation || null,
          questionId: q.id || null,
        },
      })
    },
    immediate: true,
  },
}
```

Add a helper method `getCorrectAnswerIndex(q)` that finds the index of the correct answer:
```javascript
getCorrectAnswerIndex(q) {
  if (!q || !q.answers) return null
  const idx = q.answers.findIndex(a => a.is_correct || a.correct)
  return idx >= 0 ? idx : null
},
```

If TrainingMode already has a `watch` block, merge into it. If the question data uses `.question` instead of `.text`, use the correct field name. Check the actual data shape by looking at how the question text is rendered in the template (line 55: `currentQuestion.text`).

Also emit context reset when the component is destroyed:
```javascript
beforeDestroy() {
  this.$root.$emit('virtuprof:context', { questionContext: null })
},
```
