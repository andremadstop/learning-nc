  <behavior>
    - normalizeAnswer("  192.168.0.0  ") => "192.168.0.0"
    - normalizeAnswer("192.168.0.0/24") => "192.168.0.0/24" (preserved if contains slash)
    - normalizeAnswer("010.001.000.005") => "10.1.0.5" (strips leading zeros from octets)
    - normalizeAnswer("254") => "254" (plain numbers unchanged)
    - normalizeAnswer("") => ""
    - checkAnswers({networkAddress: "192.168.1.0"}, {networkAddress: "192.168.1.0"}) => [{field: "networkAddress", correct: true, ...}]
    - checkAnswers({networkAddress: "192.168.1.0"}, {networkAddress: "192.168.2.0"}) => [{field: "networkAddress", correct: false, expected: "192.168.1.0", given: "192.168.2.0"}]
    - checkAnswers({cidr: "/24"}, {cidr: "24"}) => correct (flexible: with or without slash)
    - checkAnswers({hostCount: "254"}, {hostCount: " 254 "}) => correct (whitespace trimmed)
    - createPracticeSession() uses DEMO_SCENARIOS by default
    - createPracticeSession(customScenarios) uses provided scenarios
    - nextScenario(session) returns a scenario not yet answered, updates session.current
    - nextScenario(session) returns null when all scenarios answered
    - getProgress returns {correct, total, streak, maxStreak, remaining}
    - After correct answer: streak increments, correct increments
    - After wrong answer (any field wrong): streak resets to 0, correct stays
    - DEMO_SCENARIOS contains 3-5 scenarios covering subnet, vlsm, ipv6 types
  </behavior>
  <implementation>
    Create practiceEngine.js as pure ES module with no Vue/Nextcloud dependencies.

    normalizeAnswer(raw):
    - Trim whitespace
    - If looks like dotted IP (contains dots): split on dots, parseInt each part to strip leading zeros, rejoin
    - Return normalized string

    checkAnswers(expected, userAnswers):
    - For each key in expected: compare normalizeAnswer(expected[key]) with normalizeAnswer(userAnswers[key] || "")
    - Special case for CIDR: strip leading "/" from both sides before comparing
    - Return array of {field, correct, expected, given} objects

    createPracticeSession(scenarios?):
    - Accept optional scenario array, default to DEMO_SCENARIOS
    - Shallow-copy and shuffle the array (Fisher-Yates)
    - Return session object with {scenarios, current: null, answered: new Set(), correct: 0, total: 0, streak: 0, maxStreak: 0}

    nextScenario(session):
    - Find first scenario in shuffled list whose id is not in session.answered
    - Set session.current, return it (or null if all done)

    submitAnswer(session, fieldResults):
    - fieldResults = output of checkAnswers
    - session.total++
    - session.answered.add(session.current.id)
    - If all fields correct: session.correct++, session.streak++, session.maxStreak = max(maxStreak, streak)
    - If any field wrong: session.streak = 0

    getProgress(session):
    - Return {correct, total, streak, maxStreak, remaining: scenarios.length - answered.size}

    DEMO_SCENARIOS: 5 hardcoded scenarios:
    1. Easy subnet: "Berechne Netzadresse und Broadcast fuer 192.168.10.0/26" => {networkAddress: "192.168.10.0", broadcast: "192.168.10.63", hostCount: "62"}
    2. Easy subnet: "Wie viele Hosts passen in 10.0.0.0/28?" => {hostCount: "14", subnetMask: "255.255.255.240"}
    3. Medium subnet: "Bestimme die Netzadresse fuer die IP 172.16.45.130/20" => {networkAddress: "172.16.32.0", broadcast: "172.16.47.255", cidr: "/20"}
    4. Medium VLSM: "Ein /24 Netz wird geteilt: 100 Hosts und 50 Hosts. Welchen Prefix bekommt das groessere Subnetz?" => {cidr: "/25"}
    5. Easy IPv6: "Wie lautet die Netzadresse von 2001:db8:abcd:0012::1/48?" => {networkAddress: "2001:0db8:abcd:0000:0000:0000:0000:0000"}
  </implementation>
