# Phase 23 Plan 01: NC Files Integration

## Objective

Implement `LernbotFileService` that creates and manages Obsidian-compatible Markdown notes in the user's Nextcloud home directory. Expose two API endpoints for listing and writing notes. No DB migration required — all persistence is via the NC Files API.

## Context

- @app/lib/Service/LernprofilService.php — Phase 22 service (pattern to follow)
- @app/lib/Controller/LernprofilController.php — Phase 22 controller (pattern to follow)
- @app/appinfo/routes.php — route registration
- @app/lib/AppInfo/Application.php — DI container (autowired, no manual registration needed)

## Tasks

### Task 1: LernbotFileService — folder setup (FILES-01, FILES-03)

**Type**: auto
**Done when**: `ensureLearningFolder($userId)` creates `/Learning/`, `/Learning/Zusammenfassungen/`, `/Learning/Schwachstellen/` in the user's NC home if they don't exist yet. Returns the `/Learning/` IFolder node.

Implementation:
- New file: `app/lib/Service/LernbotFileService.php`
- Constructor: inject `IRootFolder $rootFolder` (OCP\Files\IRootFolder)
- Method `ensureLearningFolder(string $userId): \OCP\Files\Folder`
  - `$userFolder = $this->rootFolder->getUserFolder($userId)`
  - Create `Learning` subfolder if not exists
  - Inside it, create `Zusammenfassungen` and `Schwachstellen` if not exist
  - Return `$userFolder->get('Learning')`
- Namespace: `OCA\Learning\Service`

### Task 2: LernbotFileService — note write/update (FILES-02, FILES-04, FILES-05)

**Type**: auto
**Done when**: `writeNote($userId, $subfolder, $filename, $content, $meta)` creates or updates a `.md` file. `buildFrontmatter(array $meta)` produces valid YAML. Notes contain Wiki-Links and Tags.

Implementation (add to LernbotFileService.php):
- Method `buildFrontmatter(array $meta): string`
  - Produces YAML block: `---\ncreated: ...\nsource: ...\ntopic: ...\nstatus: ...\nchapter: ...\n---\n`
  - Keys from $meta, missing keys silently skipped
  - Date: ISO 8601 (`date('c')`)
- Method `writeNote(string $userId, string $subfolder, string $filename, string $bodyMarkdown, array $meta = []): void`
  - Calls `ensureLearningFolder($userId)` to guarantee structure
  - Navigates to subfolder (or root of Learning if empty string)
  - `$fullContent = buildFrontmatter($meta) . "\n" . $bodyMarkdown`
  - Create file if not exists, call `putContent()` to write/update
  - Filename must end in `.md` — enforce it
- Method `listNotes(string $userId, string $subfolder = ''): array`
  - Lists `.md` files in `/Learning/` (or subfolder)
  - Returns array of `['name' => ..., 'path' => ..., 'modified' => ...]`
  - Handles non-existent folder gracefully (return [])

Wiki-Links and Tags contract: callers (Phase 24+) embed `[[...]]` and `#tag` in `$bodyMarkdown`. The service does NOT inject them automatically — but `writeNote` must NOT strip them either (no sanitization of content).

### Task 3: LernbotFilesController — API endpoints

**Type**: auto
**Done when**: Two routes registered and working:
- `GET /api/lernbot/files` — lists notes in /Learning/ (optional `?subfolder=` param)
- `POST /api/lernbot/note` — creates/updates a note

Implementation:
- New file: `app/lib/Controller/LernbotFilesController.php`
- Namespace: `OCA\Learning\Controller`
- Constructor: inject `IRequest`, `?string $userId`, `LernbotFileService`
- `listFiles(?string $subfolder = null)` — `@NoAdminRequired`, rate limit 60/min
- `writeNote()` — `@NoAdminRequired`, rate limit 20/min
  - Reads JSON body: `subfolder`, `filename`, `body`, `meta` (array)
  - Validates: filename non-empty, no path traversal (`..`), no `/` in filename
  - Returns `{'path': '...', 'action': 'created'|'updated'}`
