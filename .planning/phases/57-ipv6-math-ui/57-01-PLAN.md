  <behavior>
    - expandIPv6('2001:db8::1') === '2001:0db8:0000:0000:0000:0000:0000:0001'
    - expandIPv6('::1') === '0000:0000:0000:0000:0000:0000:0000:0001'
    - expandIPv6('fe80::1%eth0') returns null (zone IDs not supported)
    - expandIPv6('invalid') returns null
    - parseIPv6('2001:db8::1/48') returns { groups: [8 uint16], prefix: 48 }
    - parseIPv6('192.168.1.1/24') returns null (IPv4 rejected)
    - parseIPv6('2001:db8::1/129') returns null (prefix > 128)
    - calculateIPv6Subnet('2001:db8:abcd:1234::1', 48) returns correct network (2001:0db8:abcd:0000:...), first/last host, host count as BigInt
    - ipv6AddressType correctly identifies: fe80::1 = 'Link-Local', 2001:db8::1 = 'Global Unicast', ff02::1 = 'Multicast', ::1 = 'Loopback', fc00::1 = 'Unique Local'
    - ipv6ToBitArray returns 128-element array of 0/1
    - formatIPv6 converts groups back to colon-hex string (full form, no shorthand — for display clarity)
  </behavior>
  <action>
    Write tests FIRST in app/tests/unit/ipv6Math.test.js (RED), then implement in app/src/utils/ipv6Math.js (GREEN).

    Implementation approach — use BigInt for 128-bit arithmetic:
    - `expandIPv6(input)`: Parse shorthand, expand :: to fill 8 groups, pad each group to 4 hex chars. Return null on invalid input. Strip zone IDs (%...) before rejecting — actually, just reject inputs with % as unsupported.
    - `parseIPv6(input)`: Accept "addr/prefix" format. Split on '/', validate prefix 0-128, call expandIPv6 on address part. Return { groups: Uint16Array(8), prefix: number } or null.
    - `ipv6ToBigInt(groups)`: Convert 8 uint16 groups to single BigInt. `groups[0] << 112n | groups[1] << 96n | ...`
    - `bigIntToGroups(bigint)`: Reverse — extract 8 groups from BigInt via shift+mask.
    - `calculateIPv6Subnet(address, prefix)`: Like IPv4 calculateSubnet but with BigInt. Compute network = ip & mask, last = network | ~mask. Return { network, firstHost, lastHost, hostCount, prefix, groups, networkGroups }.
    - `ipv6AddressType(groups)`: Check first group/bits: fe80::/10 = Link-Local, 2000::/3 = Global Unicast, ff00::/8 = Multicast, ::1 = Loopback, fc00::/7 = Unique Local, :: = Unspecified. Return German label string.
    - `ipv6ToBitArray(groups)`: Return 128-element array [0,1,...] from groups.
    - `formatIPv6(groups)`: Join groups as 4-char hex with colons (full expanded form for unambiguous display).

    Do NOT use any external libraries — BigInt is native JS.
    Do NOT modify subnetMath.js — keep IPv6 in its own file per technical notes.
    Follow same pure-function pattern as subnetMath.js (no side effects, null on invalid input).
  </action>
