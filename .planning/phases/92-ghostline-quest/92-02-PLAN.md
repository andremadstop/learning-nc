Top-level structure:
```json
{
  "campaign_id": "ghostline_quest",
  "version": "1.0.0",
  "title": "...",
  "description": "...",
  "duration_minutes": N,
  "difficulty": "intermediate|advanced",
  "focus_areas": ["dns", "firewall", ...],
  "character_recommendations": [...],
  "icon": "...",
  "workplace_npcs": [{"character_id": "...", "role_in_story": "...", "default_emotion": "..."}],
  "graph": {
    "nodes": [...],
    "edges": [...],
    "acts": [{"name": "...", "node_ids": [...]}]
  }
}
```

Node types available:
- `"story"` — narrative + npc_dialog + choices (via edges)
- `"simulator"` — `simulator: {type, scenario, pass_flag, scenario_override}`
- `"terminal"` — (NEW from Plan 01) `simulator: {type: "terminal", scenario_override: {prompt, valid_commands, ...}}`
- `"bot_correction"` — `bot_correction: {category: "ghostline", ...}`
- `"ending"` — final nodes

Edge conditions: `requires_flag`, `requires_item`, `min_reputation`, `max_reputation`
Effects: `set_flag`, `add_item`, `add_reputation: {type, amount}`
Timer: `timer: {seconds, consequence: {type: "force_edge", target_edge}}`

State-bag supports: flags, items, reputation (security, management, team), timers, simulators, bot_corrections

Existing character_ids for workplace_npcs: dr_hartmann, klaus_dau, uschi, sysadmin, security
(Can also use string names in npc_dialog.speaker without character_id mapping)
